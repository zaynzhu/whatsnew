## 背景

IMDb 现在已经能在页面上展示：

- 本地缓存状态：是否配置、是否缺文件、是否就绪。
- 手动命令：下载缓存与同步缓存。
- 最近同步状态：成功、失败、警告、运行中。

但这些信息分散在不同位置，用户仍需要自己判断下一步是先配置目录、先下载缓存，还是执行同步命令。

## 目标

本阶段完成：

1. 前端根据现有字段派生 IMDb 的“下一步提示”。
2. 数据源页展示一句清晰提示和必要命令。
3. 设置页 IMDb 配置弹窗在“本地操作”里展示同样的下一步。
4. 不新增后端路由、任务队列、命令执行能力或数据库字段。

## 非目标

本阶段不做：

- 不从网页执行 `npm run download:imdb --workspace backend`。
- 不从网页执行 `npm run sync:imdb --workspace backend`。
- 不添加后台任务、实时日志、WebSocket 或进度条。
- 不保存“已读提示”“推荐操作”之类的新状态。
- 不把 IMDb 改成自动抓取来源。

## 提示规则

只针对 `source.id === "imdb"` 且存在 `localState` 的来源派生提示：

| 条件 | 标题 | 命令 |
|------|------|------|
| `localState.status === "missing_config"` | 先配置缓存目录 | 无 |
| `localState.status !== "ready"` | 先刷新 IMDb 缓存 | `download:imdb` |
| 缓存就绪且没有 `latestRun` | 缓存已就绪，等待同步 | `sync:imdb` |
| 缓存下载时间晚于最近同步开始时间 | 缓存比同步更新 | `sync:imdb` |
| 最近同步失败 | 最近同步失败 | `sync:imdb` |
| 最近同步运行中 | 同步运行中 | 无 |
| 最近同步成功或警告 | 最近同步完成或最近同步有警告 | 无 |

## 前端设计

### 数据源页

IMDb 行在状态与风险说明下方显示一个紧凑提示块：

- 标题：当前最重要的下一步。
- 说明：为什么这么做。
- 命令：只有需要终端操作时显示。

### 设置页配置弹窗

“本地操作”区块顶部显示同样的下一步提示，下面保留完整命令列表。

这样用户能先看到推荐动作，也能看到完整可用命令。

## 安全

- 提示完全由前端从现有 API 响应计算。
- 命令只展示文本，不执行。
- 不展示路径、代理、Token、Cookie、数据库凭据或 API Key。
- 如果未来其他来源需要类似逻辑，必须先明确该来源的状态字段，不能只靠来源名猜测。

## 测试标准

必须覆盖：

- `missing_config` 提示先配置缓存目录。
- 缓存缺失或不完整提示运行下载命令。
- 缓存就绪但未同步提示运行同步命令。
- 缓存比最近同步更新时提示重新同步。
- 最近同步失败时提示重新同步。
- 最近同步成功时不再提示命令。
- 数据源页渲染下一步提示。
- 设置弹窗渲染下一步提示，且仍保留完整命令列表。
- `npm run typecheck`、`npm test`、`npm run build` 通过。
