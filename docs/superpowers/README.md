# WhatsNew Design Archive

This directory preserves point-in-time design specifications and implementation plans. It is historical evidence, not the current runtime authority.

Use these documents for current facts, in order:

1. Code and Prisma schema.
2. `README.md` and `AGENTS.md`.
3. `docs/architecture.md`, `docs/operator-runbook.md`, `docs/integration-guide.md` and `docs/handoff.md`.

`specs/` records accepted design reasoning. `plans/` records task-by-task implementation instructions that may mention old source lists, routes, test counts, constraints or pending work. Do not execute an archived plan or treat its status header as current without checking the live code and current docs first.

Some archived implementation plans are intentionally long because they contain historical code snippets and TDD steps. They are not loaded as onboarding or operational documentation and should not be expanded further.
